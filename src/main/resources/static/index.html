💼 Employee API

Spring Boot REST API — CRUD + JWT Authentication

● Running on Java 17  |  Spring Boot 3  |  H2 in-memory

Auth Endpoints

POST /api/auth/login

Employee Endpoints

GET /api/employees
GET /api/employees/{id}
POST /api/employees
PUT /api/employees/{id}
DEL /api/employees/{id}

Stack

Java 17 / Spring Boot 3.3
Spring Security + JWT
H2 In-Memory Database
nginx reverse proxy
AWS EC2 (us-east-2)
Deployed via GitHub Actions

Quick Start

# 1. Login and capture the token TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \ -H "Content-Type: application/json" \ -d '{"username":"admin","password":"admin123"}' | python3 -c "import sys,json; print(json.load(sys.stdin)['token'])") # 2. Create an employee curl -X POST http://localhost:8080/api/employees \ -H "Authorization: Bearer $TOKEN" \ -H "Content-Type: application/json" \ -d '{"firstName":"Jane","lastName":"Doe","email":"jane@example.com","department":"Engineering","salary":90000}' # 3. List all employees curl http://localhost:8080/api/employees \ -H "Authorization: Bearer $TOKEN"
